## MVP for my Challenge/Progress Tracker:

1. **Overview of all Sessions and Challenges:**
   - A page that lists the sessions (similar to my Trello cards). Each session should display the associated challenges.
   - Each challenge should have three status options (Started, Pull Request, Merged), which the user can check off, similar to the checklist in Trello.
2. **Progress Display:**
   - Show the progress for each session and the total number of completed challenges.
   - Use bars or percentages to visually represent how far a user has progressed in the challenges.
3. **Gamification:**
   - Start with a simple level system. The user can level up by completing challenges. The level names could be: Coding Beginner, Coding Monkey, Coding Ninja, Coding Pro, etc.
   - You could also add "badges," for example, for completing multiple challenges in a day or reaching a certain progress milestone.

---

## Key Features for the First Version:

- **Dashboard:** Displays sessions, progress, and the current player status.
- **Challenge Page:** Shows the challenges associated with each session and their statuses.
- **Gamification Mechanic:** Progress bars and level system.
- **Data Management:** Use a simple JSON file or a database (like MongoDB) to store information about the challenges and user progress.

---

## User Stories:

### User Story 1: Display Sessions

**As a** user  
**I want to** see all available sessions and their associated challenges  
**so that** I can quickly get an overview of all the topics and tasks.

### User Story 2: Update Challenge Status

**As a** user  
**I want to** update the status of my challenges (Started, Pull Request, Merged)  
**so that** I can track my progress on each challenge.

### User Story 3: Progress Display

**As a** user  
**I want to** see a display of my progress for all my challenges  
**so that** I stay motivated and can follow my learning progress.
